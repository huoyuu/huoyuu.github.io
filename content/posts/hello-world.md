这是本博客的第一篇文章。站点刚刚用 Hugo 搭建完成，选用了简洁高效的 PaperMod 主题，从今天起，我会在这里记录学习笔记、技术心得与生活随想。

整个站点由 Hugo 静态网站生成器构建。写作时只需要用 Markdown 完成内容，剩下的页面渲染与构建全部交给 Hugo 处理，生成速度快，维护起来也简单，非常适合长期写作。

接下来，这个站点将托管在 GitHub Pages 上，部署完成后就可以通过浏览器公开访问，每一次修改都会留下版本记录，方便随时回溯。

后续我会在这里持续更新，逐步完善分类、标签和关于页面，把这里真正变成一个属于自己的小天地。欢迎常来看看。
