## 2026-11-23

- **全站视觉改版**：首页改成「Hero + 最新日记卡片 + 更早列表 + 标签」，日记列表、归档、关于、更新日志、标签/分类、404 页统一为新版式
- 首页新增**站点数据**（篇数 / 最近更新 / 标签数）与快捷入口按钮
- **留言板**页面重做，支持深色模式，并修复留言展示与页面缓存问题

## 2026-11-21

- 日记底部新增**上一篇 / 下一篇**导航，标签前加了 `#` 号
- 移除日记底部多余的「相关日记」卡片，收紧页面模块间距

## 2026-11-20

- 上线**评论区**功能：无需登录，支持留言及回复
- 新增**更新日志**页面
- 补上**站点图标**（浏览器标签页、iOS 主屏）
- 全站强制 **HTTPS加密**，`www.huoyuu.top` 自动跳转到 `huoyuu.top`
- `robots.txt` 补上 sitemap 声明，方便搜索引擎收录

## 2026-11-19

- 本站从 GitHub Pages **迁移到 Cloudflare Pages**，启用主域名 `huoyuu.top`
- 用 Cloudflare Worker 做反向代理 + 优选线路，改善国内访问速度
- 日记支持**标签**和**分类**
- 支持**删除日记**、**重命名日记链接**
- 归档逻辑调整：勾选「归档」的日记只出现在归档页，不再出现在首页
- 修复后台日期时区问题
- 修复图片库和正文插图显示问题

## 2026-11-17

- 主题定制：头像、页脚、暗色模式、导航菜单
- 关于页补充联系方式

## 2026-11-16

- 用 **Hugo + Stack 主题**搭建本站，完成第一版部署
